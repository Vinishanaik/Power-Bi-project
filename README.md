Pizza Sales Performance Analytics Dashboard

Built a Pizza Sales Analytics Dashboard using MySQL and Power BI, uncovering key revenue drivers, customer ordering trends, peak sales periods, and top-performing product categories across 21K+ orders and their sales.

Built an interactive Pizza Sales Analytics Dashboard using Power BI and MySQL to analyze revenue, order volume, customer purchasing patterns, and product performance.
Used SQL queries for data extraction, transformation and performance analysis of across 21K+ orders.
Identified peak sales periods, revealing that weekends (Friday–Saturday) and months such as January and July generated the highest order volumes.
Analyzed product performance and discovered that the Classic category and Large-sized pizzas were the strongest contributors to overall sales and revenue.
Delivered actionable insights that could support inventory planning, product strategy, and revenue optimization.
